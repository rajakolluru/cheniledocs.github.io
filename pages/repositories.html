How they layer
chenile-parent defines versions → chenile-core provides the runtime → chenile-query-workflow-blueprints and chenile-process-management add application patterns → chenile-service-registry, chenile-proxies, chenile-security and chenile-messaging add integration → chenile-bdd and chenile-others add testing and operations → cconfig supplies runtime configuration. The cconfig source lives in the GitHub repository ajapros/config.
